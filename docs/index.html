Write with someone beside you.
In any app, in ink, above your cursor.

Lina is a free, open-source writing companion for macOS. When you pause, it tells you what it hears you saying and asks one question that takes you deeper. It never writes for you unless you ask it to.

Three modes

Think it through, tidy it up, or let it flow.

Understand

Lina reads the whole draft and writes back what it hears, why you might be writing it, one question and a thread worth following. It never touches your document.

⌥ Space answer the question

Edit

Finish a sentence and Lina offers a cleaner version of it in ink. Take it with one key or keep yours. It works in any app, sentence by sentence.

⇥ take it esc keep yours

Auto

Lina rewrites each sentence you finish in place, in your voice. Every change lands in the app's own undo stack.

⇧⌥ Space switch modes ⌘Z undo

Privacy

It's your writing. Lina keeps it that way.

Never secure fields

Password fields, secure input and apps you turn off are ignored completely.

Only where you choose

Text goes only to the model you pick. With On this Mac, it never leaves your machine.

No account, no analytics

Stats, memory and gathered clippings stay on your Mac. The code is open, so you can check.

Try it in five minutes

Download, open, start writing.

Download

Lina.zip, unzip it, and drag Lina.app into Applications.

Open it once

Lina isn't notarized yet. If macOS blocks it, open System Settings → Privacy & Security and click Open Anyway.

Allow Accessibility

The welcome screen asks for it, so Lina can read the field you're typing in and find your cursor.

Pick a model

Paste a free Nebius Token Factory key, or choose On this Mac and download one.

# If macOS still refuses to open it, clear the download flag:
xattr -dr com.apple.quarantine /Applications/Lina.app

# Or build it from source (Xcode 16 command line tools):
git clone https://github.com/Sppdd/lina.git && cd lina
scripts/build-app.sh --open
